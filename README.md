# TOP MOTOS 021 — pronto para GitHub Pages

## Publicar

1. Extraia este ZIP.
2. Envie os arquivos extraídos para a raiz do repositório no GitHub. O index.html deve aparecer diretamente na página inicial do repositório, sem ficar dentro de outra pasta. Não envie apenas o ZIP.
3. Abra Settings > Pages.
4. Em Build and deployment, selecione Deploy from a branch.
5. Selecione a branch main e a pasta / (root). Clique em Save.
6. Aguarde a publicação e abra o link exibido pelo GitHub Pages.

Se a branch do repositório tiver outro nome, selecione a branch que contém index.html.

Não precisa de npm, Node.js, Vite, terminal ou GitHub Actions personalizado. O HTML inclui o JavaScript, o CSS e as imagens da moto. As fontes usam Google Fonts, com fontes alternativas caso não haja acesso.

Para visualizar no computador, abra index.html após extrair.

O site mantém o catálogo demonstrativo e os espaços para dados reais da empresa. O número do WhatsApp ainda não foi fornecido; os botões oferecem o Instagram e a mensagem para copiar. Endereço, horários, fotos originais e estoque real precisam ser confirmados antes do uso comercial.
